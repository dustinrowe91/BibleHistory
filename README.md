# Bible History

An interactive timeline of the major events of the Bible, from Creation to Revelation.

- Ten eras, from Beginnings through the Early Church, on a scaled overview bar
- Search across events, people, and books; filter by Old or New Testament
- Every church named in Acts, marked on the timeline, with a "Churches in Acts only" filter
- Tap any event for a summary, the people involved, and a link to the passage on BibleGateway

It's a single static page: open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → deploy from `main`).

Dates follow a conservative chronology (Exodus c. 1446 BC) and are approximate.
